# 進場後什麼時候出場比較好 (選股 / 進場不變) — 研究 40 (2026-11-18)

`scripts/40_exit_research.py` (GHA「Research exit timing」, run 44234117272)。期間 2020-01-02 ~ 2026-11-13, 現行規則每日先到先做最多 10 檔 (**等權、不含 11-18 起的品質篩選 / 加權**), 共 6,613 筆。
每筆含成本 0.23%; 規則出場 (盤中市價) 另扣 0.1% 滑價, 獲利目標為限價 (要穿過才成交); 停損一律保留 (反彈破區間高); 同一分鐘同時碰停損與其他出場一律當先停損。
樣本外 = 2022~2026 逐年走動式: 每年只用之前年份挑參數 / 訓練。挑參數標準 (Ray: 以回撤小為準) = 訓練期 年均/最大回撤 最大, 且年均 ≥ 現行 70%; 都贏不了現行就維持現行。
RL = 批次 Q-learning (政策迭代): 狀態 = 時段 7 × 浮動損益 7 × 從進場後最低點反彈 4 × 在 VWAP 上/下 2 (392 個), 動作 = 續抱 / 平倉; 每個狀態至少 60 筆交易才允許學「平倉」。
自我檢查: RL 環境在「永不提前平倉」時與現行回測每筆差 0。

## 結論
- **沒有一種出場法能同時多賺又少回撤**。現行 (停損 / 13:30 收盤) 在「賺多少」上幾乎是最好的: 所有提早出場的規則全期年均都 ≤ 現行 (132 萬)。
- **要降回撤, 最穩的是「賺到 2% 後停損移到進場價 (保本)」或「賺 2% 後從最低點反彈 3% 出 (移動停利)」**: 全期年均 132 → 116 / 109 萬 (少 12% / 17%), 最大回撤 −27 → −20 / −19 萬, 而且現行最深的 5 段回撤每一段都變淺 (例: 2026-04 −20 → −10 / −6、2025-12~2026-01 −17 → −10 / −3) → 不是只靠某一年。走動式樣本外 (2022~2026) 也成立: 移動停利 137 萬 / 回撤 −19 / Sharpe 3.33、保本 133 / −20 / 3.23, 現行 142 / −27 / 3.08。
- **固定時間出場、提早平倉都更差**: 10:00 平 −45 萬/年、12:00 平 60 萬、13:25 市價平 123 萬 (比收盤競價少 9 萬, 多一次滑價)。時間停損、站回 VWAP 出也都不如現行 (同研究 25/26)。
- **RL 沒有贏過簡單規則**: 只用 1 分K 的 RL 樣本外 136 萬 / −25; 全期訓練也只學到 2 個該平倉的狀態 (09:30~10:30 已賺 >5% 且還在低點附近、VWAP 下), 跟「賺 5~6% 回補」同一件事。樣本太少 (每年約 1,000 筆), 狀態一細分就不夠學。
- **加日K**: 6 個日K特徵一次加一個, 只有「開盤 vs 前 20 日高」樣本外較好 (144 萬 / −21 / Sharpe 3.27), 其他 5 個 ≈ 不加或更差。試了 6 個挑最好的, 很可能是運氣, 不建議採用。
- 風險趨避 RL (λ) 越大越早平倉, 回撤沒有比較小 (λ=0.05: 102 萬 / −25), 不如保本 / 移動停利。
