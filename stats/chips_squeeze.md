# 融資融券 / 小台散戶多空比 → 放空會不會比較容易被軋 (重點摘錄)

腳本 `scripts/37_fetch_chips.py` (抓資料) + `scripts/38_chips_squeeze.py` (分析), GHA「Research chips (margin / MTX retail) x ORB5」(mode=full, 資料用 actions/cache 保留, 第二次起只補新日期), 完整表在 workflow log。
資料: 證交所 MI_MARGN (上市) + 櫃買融資融券餘額 (上櫃) 每日, 2019-12-02 ~ 2026-11-13, 326 萬列 / 2,364 檔；小台三大法人未平倉 + 全市場未平倉 1,689 日 (期交所下載只給近 3 年, 更早用 FinMind；2026-10 兩邊逐日核對完全相同)。

逐年 (減 ≥1.7% 的日子 vs 其他, 每筆%): 2020 −0.15 / 0.65、2021 −0.24 / 0.64、2022 −0.23 / 0.62、2023 0.02 / 0.53、**2024 0.86 / 0.49**、2025 −0.15 / 0.41、2026 −0.13 / 0.45 → 7 年中 6 年較差。
解讀: 融資大減 = 剛殺過一波、斷頭 / 停損後, 隔天容易反彈軋空；融資增加 = 散戶在追, 跳空開高的股票較容易被倒貨。

## 結論
1. 個股融資融券看不到「軋空」風險: 券資比高、融券多的股票停損率沒有更高, 每筆反而較好；拿來過濾都讓日淨下降。不採用。
2. 停券前 7 天 (強制回補窗口) 兩段都較差, 但改 0.5 格 Sharpe 只 2.86 → 2.89, 影響很小, 可有可無。
3. 小台散戶多空比沒有穩定關係, 不採用。
4. **候選: 大盤融資 5 日減少 ≥3% (或 ≥1.7%) 的隔天不做**: 日淨 0.176 → 0.193%、Sharpe 2.86 → 3.30、MDD −9% → −6%, 探索 / 驗證都改善, 7 年中 6 年成立 (2024 例外)。注意門檻是看過資料才挑的, 減 ≥3% 的日子不多 (約 535 筆被跳過)；上線需每天盤前抓前一日上市 + 上櫃融資餘額。未上線, 由 Ray 決定。
