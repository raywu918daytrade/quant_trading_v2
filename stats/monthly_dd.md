# 降低每個月的最大回撤 (新規則: 品質篩選 + 權重) — 研究 41 (2026-11-18)

`scripts/41_monthly_dd.py` (GHA「Research monthly drawdown」= 33 → 40 --build-only → 41, run 44236588812)。
期間 2020-01-03 ~ 2026-11-13, 2,392 筆 (11-18 起的線上規則: 砍 5 分成交額 <1.5 億 / 一檔 >0.2%, 權重 0.75/1.5/3 格, 當日 ≤10 格), 300 萬本金。成本 0.23%, 盤中出場另扣 0.1%; 停損保留。
月內回撤 = 每月從 0 起算、相對當月最高點的最大跌幅 (萬)。風控只用到前一天的資訊。自我檢查: 現行出場與 33 回測每筆差 0、RL 環境差 0。

## 結論
- 現行 (新規則): 年均 139 萬, 每月最大回撤平均 −6.8 萬、最差 −22 萬, 83 個月中有 20 個月回撤超過 10 萬。2026 最差 (平均每月 −13.7 萬)。
- **換出場法沒用**: 走動式樣本外 (2022~2026) 只換出場法 126 萬 / 平均月回撤 −6.9 / 最差月 −29 (比現行 134 / −7.0 / −22 還差)。最好的固定候選「賺 2% 後從最低反彈 3% 出」: 117 萬, 平均 −6.0、最差 −19.8, 只把 4 個 ≤−20 萬的月份壓到 0 個, 少賺 16%; 舊規則上最好的「保本停損」在新規則下變差 (最差月 −25.5)。
- **RL 也沒用**: 虧損加重的 RL 樣本外月回撤 −6.7~−6.9, 年均卻掉到 99~127 萬; κ=2 直接虧錢。
- **唯一能確實壓住每月回撤的是「當月回撤到 5 萬就停做到月底」**: 平均 −6.8 → −4.8、最差月 −22 → −11.5、超過 10 萬的月份 20 → 4; 代價是年均 139 → 89 萬 (少 36%), 虧損月 19% → 29%, 而且**全期最大回撤一樣是 −22 萬** — 它只是把回撤切在月底, 下個月又重新開始, 總風險沒有變小。走動式只有 2024 年選到它, 樣本外整體「只加風控」113 萬 / −6.9, 沒有改善。
- 門檻放寬 (8、10、15 萬) 或「月虧到 X 就停」更差: 少賺又沒壓到回撤, 全期回撤還變大 (月回撤 10 萬停做 −41 萬), 因為停在低點錯過反彈。
- 要每月回撤小, 最乾淨的方法其實是**降部位**: 每月回撤與損益都和部位等比例 (例如 7 成部位 → 平均月回撤約 −4.8、年均約 97 萬), 效果和「月回撤 5 萬停做」差不多, 但不會讓全期回撤變大, 也不用多一條規則。

## 7. RL 加大盤 / 類股 (2026-11-18 晚, run 44288143750)
大盤 = 均額 ≥1 億上市櫃股票每分鐘「相對當日開盤」等權平均; 類股 = 同產業 (扣掉自己, ≥3 檔, 97% 的交易有); 特徵用「進場後到現在」的漲跌。RL 狀態改粗格 (時段 4 × 浮動損益 4 × VWAP 上下 2) 再乘大盤 3 格 / 類股 4 格。
- 大盤 / 類股確實和結果有關: 進場後到收盤的大盤漲跌與本筆報酬相關 −0.39、類股 −0.46 (它們漲, 空單就賠)。
- 但盤中拿來決定出場沒用: 它們和個股同時動, 看到大盤 / 類股轉強時個股通常也已經反彈, 現在平倉不比抱到收盤好。

結論: 加大盤 / 類股的 RL 都 ≈ 現行 (差 1~2 萬、月回撤差 ±0.1 萬, 屬雜訊), 固定訓練版還更差。大盤 / 類股規則要嘛少賺很多, 要嘛月回撤沒變小。仍以「賺 2% 後從最低反彈 3% 出」最平衡, 但也只是小改善。
