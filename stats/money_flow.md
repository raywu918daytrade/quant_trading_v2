# 資金流向 (三大法人 / 融資融券 / 八大行庫 / 分點) → 現行空單期望值 (研究 44, 2026-11-18)

`scripts/43_fetch_flows.py` (抓資料) + `scripts/44_money_flow.py` (分析), GHA「Research money flows」(mode full)。完整輸出在該 workflow 的 artifact `money_flow`; 本檔是整理後的結論與重點表。

## 結論

- **沒有一個資金流向指標穩定到值得上線。** 掃了 29 個指標 × 兩端 × (不做 / 0.5 格 / 1.5 格) = 174 組規則, 只有 1 組「探索、驗證兩段都改善」, 而且逐年只贏 4/7 年 (見 §3), 隨機也會跑出這種結果。
- **最一致的現象: 前一天法人 (尤其投信) 大買的股票, 隔天放空每筆比較差。** 投信前 1 日買超 ≥ 均量 2.9% 的單 (14%): 每筆 探索 0.22% / 驗證 0.20%, 其他 1.00% / 0.55%; 三大法人前 1 日五分位兩段都「越買越差」。但拿來不做或減半, 名額讓給後面的單後組合幾乎沒變 (Sharpe 探索 −0.04 / 驗證 +0.18), 因為被換上來的單也沒比較好。可以當觀察, 不足以當規則。
- **大盤層面 (外資 / 投信 / 自營商 / 三大法人合計買賣超、大盤融資、大盤當沖比重) 決定當天做不做: 全部沒用**, 不做都少賺 20~70 萬/年。
- **舊候選「大盤融資 5 日減 ≥3% 隔天不做」用新規則重算後變弱**: 年均 140 → 140、Sharpe 2.71 → 2.83, 逐年 7 年有 5 年略輸, 只有 2026 年 +13 萬。不建議上線 (研究 38 用舊規則時是 2.86 → 3.30)。
- 融資 / 融券 / 當沖率 (隔日沖替代) 個股層面: 都不單調, 兩段方向不一致。和研究 38「個股無軋空跡象」一致。
